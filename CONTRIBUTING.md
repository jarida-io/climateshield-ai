# Contributing to ClimateShield AI

Everyone is welcome. Developers, data scientists, public health researchers, UX designers, translators, documentation writers.

## How to Contribute

1. Fork this repository
2. Create a branch: `git checkout -b feature/your-feature-name`
3. Commit: `git commit -m "Add: description"`
4. Push: `git push origin feature/your-feature-name`
5. Open a Pull Request

## Priority Areas

- ML model improvement (`ml-predictor/`)
- Open health-data standards integration (`immunization-integration/`)
- Swahili SMS template translations
- CHW Android app (coming soon)
