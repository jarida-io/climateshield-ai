# Immunization Integration

Connects ClimateShield AI to the Child Immunization Tracker and open health-data standards.

## Purpose

When the Alert Engine identifies high outbreak risk for a county, this module queries the Child Immunization Tracker for children with overdue or missing vaccinations in that county, enabling targeted alerts.

## Status

In development. Planned integration with open health-data standards for interoperability with MOH systems.
