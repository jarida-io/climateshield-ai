# Dashboard

County health officer interface showing outbreak risk heatmaps and vaccine demand forecasts.

## Status

Wireframes complete. Built with React.js + Leaflet.js for interactive county-level maps.

## Planned Features

- Real-time risk heatmap by county (colour-coded HIGH / MEDIUM / LOW)
- Vaccine demand forecast based on at-risk population
- Alert history and CHW dispatch log
- Export reports (PDF / CSV)
